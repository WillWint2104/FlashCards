Where Marginal stops and authored content begins

A question is authored outside the application, against a generated specification, and reaches a student through one boundary. Everything on the left is written by someone who has never read the source. Everything in the middle refuses before anything is written. Nothing on the right reads a package yet.

Four answers, never one count

Because the person reading the report does something different for each.

Error

The package is wrong. A ref names nothing and was never declared. A value is outside a list. An old prose join came back.

Blocked

The package is right. It declared a dependency and the library does not have it. There is nothing in the package to fix.

Shortfall

Well formed. Something it asks for cannot be given in full yet. It imports, and it is recorded.

Warning

Worth recording. House style, and nothing a student would be harmed by.

No score anywhere. Twelve complete arguments and no sourced evidence is pathway-guided and not evidence-complete. It can never be four fifths of anything.

Support unavailable · what the engine cannot give

Kept apart from capability, and from faults. A valid question can ask for something Marginal does not have.

judgement shapesevery authored sentence shape is causal, so an Evaluate question is offered none and the panel is withheld
guided writing8 of 22 known commands assign no family. A Compare question imports and is offered no argument scaffolding
There is no fallback. The engine's own resolver returns causal when nothing matches, which is how a Compare question came to be scaffolded as a cause. Unknown does not import; known and unsupported is withheld, never defaulted.
