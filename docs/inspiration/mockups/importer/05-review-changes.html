What each mark means

+ new. Does not exist yet. Publish creates it.

= already exists. Publish reads it and leaves it exactly as it is.

x not published. Either the package was rejected, or its id is taken. Nothing from it is written.

There is no fourth mark, because there is no overwrite. A first import adds or it declines.

What gets stored

The unit is the package document. Publish stores the whole file as authored, and everything Marginal uses is derived from it and can be rebuilt.

So this page does not list a package's individual properties, and does not need to. A field written against a later contract version is stored with the rest, unread and unchanged.

How importing works

Parse asks whether the file is a readable package. Validate asks whether what it says is valid. Resolve references asks whether the things it names exist. Review shows what would change. Publish writes it, and is the only step that does.
