How importing works

Parse asks whether the file is a readable package. Validate asks whether what it says is valid. Resolve references asks whether the things it names exist. Review shows what would change. Publish writes it, and is the only step that does.

Where a blocked dependency would appear

A shortfall is a fact about a record, so the library table is its home. A blocked dependency is a fact about a package: it decides which questions import. So it does not get a row in that table. It promotes a card above it, and the shape of the screen changes with the state.
