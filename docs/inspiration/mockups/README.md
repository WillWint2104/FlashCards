# Mockups

One image plus one note per idea. The note is what makes the image usable months
later: an image on its own cannot say which part of it mattered.

`2026-08-18-composer.png` beside `2026-08-18-composer.md`:

```
---
title:   Sentence composer, resting state
date:    2026-08-18
status:  active
governs: guided mode, the active writing screen
---

What this is showing
- the guide sits directly under the line being written, not in a margin
- accepted sentences read as ordinary prose above it
- argument and evidence are chips, not cards

What it is NOT showing
- the drawer open state, which is a separate mockup
- final colours

Open questions
- does the response map belong on the left or collapse into the top bar?
```

Say what the image is showing, what it is deliberately not showing, and anything
still open. That last section is the one that saves the most time.
